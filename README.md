What the game is about :

This is a platform where beginners can learn about Scheduling in Operating Systems by providing an interactive Simulation of Job tracking.
Users are provided with a result tab that displays Arrival Time, Waiting Time, Turnaround Time, and other important metrics after they successfully complete the game.

Steps to run the game :

1. Download Godot.
2. open file named as "project.godot"
3. Click on the play button located in top-right corner
4. To export the game, click on project.
5. Then, click on export.
6.  Select "windows runnable".
7.  A Game file with the extension .exe will be created
